PURPOSE
-------
This document describes the Tecplot ASCII files in the FINAL prepared packages
for three CFD++ computations of the NASA CRM wing/body/tail configuration.
These are three submissions for DPW8/AePW4 TEST CASE 3, not three different
workshop test cases.

SUBMISSIONS AND PACKAGE VERSIONS
--------------------------------
008.01  Cadence L2, half-span  DPW8_008_01_Metacomp_CadenceL2_Submission_v2.zip
008.02  MIME, half-span        DPW8_008_02_Metacomp_MIMEHalf_Submission_v2.zip
008.03  MIME, full-span        DPW8_008_03_Metacomp_MIMEFull_Submission_v2.zip

Each ZIP contains 8 Tecplot ASCII data files plus 1 quality-assurance report.
Files ending in .dat and .tec are both Tecplot ASCII data files. The
"FULL_RAW" force history is provided to document the complete calculation
sequence; the "CORRECTED" force history is the primary continuous positive-
time version. "CORRECTED" refers to chronological assembly of restart data,
not to adjustment of the force coefficients.

COORDINATE / MOMENT REFERENCE CONVENTION
----------------------------------------
The CFD grids retain the coordinate origin from an earlier JAXA website
diagram, subsequently removed. Instead of translating the grid, the moment
center was shifted in the existing grid coordinate system to correspond to
the intended JAXA physical moment center. The source force files use the
moment center (x,y,z) = (0.676660, 0, -0.023698) m.

FILE TYPES AND HOW TO INTERPRET THEM
------------------------------------
BendingTwist.dat:
    Wing deformation history, VARIABLES = TIME, BEND, TWIST. Separate
    Tecplot zones for span stations (signed ETA in the full-span case).
Surface_Cuts_Cp.dat:
    Mean pressure coefficient at sectional cuts, VARIABLES = x, y, z, Cp.
    One Tecplot zone per cut; source rows are sorted by x.
Surface_Cuts_Cp_rms.dat:
    RMS pressure-coefficient cuts, VARIABLES = x, y, z, Cp_rms.
UnsteadyForceMoment_CORRECTED.dat:
    Main continuous positive-time force/moment coefficient history.
    Contains iteration, time, convective time, lift, drag, moments and
    Cartesian force coefficients. Restart overlaps are resolved by retaining
    the final occurrence of each step; zero-time initialization is omitted.
UnsteadyForceMoment_FULL_RAW.dat:
    Complete, unfiltered source chronology including zero-time initialization,
    restarts, duplicate iterations and startup algorithm-switch transients.
VirtualKulite_PressureHistories.dat:
    Time-dependent virtual surface pressure probes. One zone per probe;
    variables Time_s, Time_CTU, Pressure_Pa, Cp. Probe coordinates are stored
    in zone metadata. Time_CTU = Time_s * Uinf / reference_MAC. Pressure is
    interpreted as absolute Pa (not explicitly labeled in original probes).
Wing_Pressure.tec:
    Finite-element surface mesh with X,Y,Z, mean pressure (p_mean) and Cp.
Wing_RMS_Pressure.tec:
    Matching surface mesh with X,Y,Z, RMS pressure (p_rms) and Cp_rms.
QA_REPORT.txt:
    Detailed source/provenance, conversion checks and known caveats.

IMPORTANT DISTINCTIONS / KNOWN QUALIFICATIONS
---------------------------------------------
1. Full-span (008.03) force-coefficient reference area is 0.179014 m^2;
   half-span runs use 0.089507 m^2. Do not mix these normalizations.
2. Sectional mean Cp and RMS Cp cuts use slightly different reported eta
   values. Their source station values were preserved; no interpolation was
   applied to make them coincide.
3. The full-span left-wing cuts are separately annotated in the zone titles
   and metadata. All supplied virtual Kulite probes are on the positive-Y
   wing even for 008.03.
4. Large, nonphysical force excursions during numerical algorithm switches
   in the startup history are intentionally retained. The FULL_RAW files also
   preserve original restart/initialization chronology.
5. Missing pressure/viscous drag decomposition in force histories uses
   the -999 sentinel. C_M_pitch is a duplicate of C_My, matching the
   established output convention.
6. The original Kulite source files do not explicitly specify units for
   pressure; the Tecplot output uses the assumed absolute-Pa interpretation.
7. Source data and processing were programmatically checked as detailed
   in the case-specific QA reports; an interactive Tecplot 360 import has
   not been independently performed.
8. The submission date in deformation metadata remains TBD where it was not
   supplied. Use the actual delivery date when submitting.
